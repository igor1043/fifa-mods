## Novo complemento para o Robson

São **650 arquivos estáticos**: 33 do vestiário, duas texturas do
globo, `data/ant.cbac` (SubsOn), mascotes, objetos de apresentação das competições,
suportes de bola, cabine de campo e iluminação neutra dos titulares. O catálogo
`data/catalogs/presentation_assets.json` registra os recursos de apresentação,
com tamanho e SHA-256. Backups de competições e metadados de construção ficam fora.

O complemento substitui o ZIP menor anterior. Não contém a sala interna do VAR,
saves, SQL financeiro, logs ou caches pessoais. Escudos e bandeiras continuam
usando o catálogo do jogo; bibliotecas completas de estádios e áudio do usuário
não são redistribuídas. Este ZIP complementa os mods, não substitui a base FIFA.

`Build-PortablePackages.py` verifica CRC, tamanho e SHA-256, exporta o commit Git
para uma pasta Unicode vazia e aplica o complemento. A conferência roda o Server
congelado e prepara os workers sem copiar o runtime local e sem abrir o FIFA.

## Validação e limites

O perfil completo passou em **113 comandos**, com
**704 testes Python** e os testes nativos/integrações do perfil.
Após a alteração final para 40%, mais 12 testes dos painéis/configuração e
a compilação/testes nativos das cenas foram executados novamente.
O executável congelado passou no self-test; 80 módulos embutidos foram
comparados com os fontes publicados. [Relatório](VALIDACAO_20261025.json).

Para reproduzir: `python -B ModCarrerMode/source/scripts/run_regressions.py
--game-root "PASTA DO FIFA"`. A integração WARP/globo também pode ser executada
com `--group browser-native`. Dependências em `source/requirements-tests.txt`;
testes nativos exigem MSVC x64 e Windows SDK. FIFA e Server devem estar fechados.
As ferramentas históricas de autoria de narração indisponíveis ficam explicitamente
fora do perfil público, registradas no resultado; não são contadas como aprovadas.

Testes offline não comprovam todas as transições visuais da engine. O novo tempo
de permanência das cenas e duas partidas consecutivas com o ajuste de estádio
ainda precisam de conferência visual. A renderização dos titulares no PC do
Robson também precisa da atualização completa e do teste local dele.
