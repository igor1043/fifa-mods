# Correção e complemento completo — 29/10/2026, R2

Esta revisão substitui a entrega anterior do mesmo dia. Use o código atualizado
da branch `fifa-friends-v12` e o novo
**FIFA-Friends-Assets-Complementares-20261029-R2.zip**, extraído na raiz da base
FIFA Friends depois do código, com FIFA e Server16 fechados.

## Server16

Os fontes funcionais do jogo foram sincronizados com o desenvolvimento e a
branch `fifa-friends` do repositório do Server16. O novo executável contém as
revisões de `app`, `asset_runtime`, `file_tools` e `stadium_runtime`.

A aplicação/restauração dos modelos de estádio, cadeiras, posições de público e
redes passa pela verificação de acesso nas pastas de destino administradas pelo
Server. Ela reativa a herança e acrescenta permissão de modificação para o SID
do usuário atual. Não troca o proprietário nem apaga as entradas existentes.
Falhas são registradas no log, com tempo limite. Os testes verificam os comandos
e a ordem entre preparação das permissões e cópia dos arquivos.

O executável é construído a partir da última versão publicada, substituindo os
quatro módulos alterados e conferindo byte a byte os recursos restantes. São
preservados 1.030 módulos Python e 1.537 recursos do pacote. O autoteste
congelado e a comparação do código embarcado com as três pastas fazem parte
da validação. A versão interna continua 0.2.19; o identificador desta entrega
é **29/10/2026 R2**, acompanhado por hash do EXE e commits próprios.

## Catálogo e ZIP

O catálogo público SQL e todas as fotos atuais são capturados juntos. O teste
de distribuição exige que cada imagem referenciada pelo catálogo esteja no
complemento, inclusive a foto padrão. A quantidade de imagens é lida do
manifesto, permitindo ampliar o acervo sem uma contagem fixa no teste.

O ZIP é refeito do zero. Continua completo: vestiário, globo, pose, apresentação,
mascotes, cabine do VAR, SubsOn e integração visual do Robson permanecem no
pacote. Não é um delta de fotos e não exige acumular os ZIPs anteriores.
Requer a base FIFA Friends; imagens/uniformes originais continuam vindo dela.

Saves, bancos pessoais, cache, runtime e executáveis intermediários de `dist/`
não são publicados. O único SQLite novo distribuído é o catálogo público de
técnicos, que não contém contratos ou preferências de uma carreira do usuário.

O manifesto `ModCarrerMode/data/catalogs/asset_complement.json` fixa arquivos,
tamanhos e hashes. A entrega deve passar também pela combinação Git + ZIP numa
pasta vazia, com execução dos auxiliares sem abrir FIFA ou instalar drivers.

Captura desta R2: **1.957 técnicos, 1.024 imagens e 1.967 arquivos externos**.
Foram aprovadas **76 suítes com 936 testes Python**, além de 67 testes executados
no repositório canônico do Server16 e do autoteste do executável. O catálogo
público passou na verificação SQLite, sem imagens referenciadas ausentes.
