# Fontes nativos agrupados

| Diretório | Recurso | Execução |
|---|---|---|
| [frontend_stadium](frontend_stadium/) | Estádio de fundo do menu e da carreira | `mods/frontend_stadium/frontend_stadium_native_v11.dll` |
| [panorama_drone](panorama_drone/) | 37 tomadas da panorâmica | `mods/panorama_drone/panorama_drone_v5.dll` |
| [extra_scenes](extra_scenes/) | Cenas de técnicos e mascotes | Desativado; fontes preservados |
| [first_person](first_person/) | Câmeras do jogador | Biblioteca embutida no Server16 |
| [career_overlay](career_overlay/) | Layouts da carreira | Recursos de interface |

Os demais módulos mantêm seus caminhos em `ModCarrerMode/source/<mod>/`,
preservando os scripts e as referências existentes. Mascotes ficam em
`source/mascot_photographer/`, e pirotecnia em `source/stadium_pyrotechnics/`.

O [índice das DLLs](../../mods/README.md) informa os caminhos usados pelo jogo.
Não copie fontes, builds ou backups para as pastas de execução dos módulos.
