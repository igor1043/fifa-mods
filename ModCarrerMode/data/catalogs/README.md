# Catálogos auxiliares

Estes arquivos de texto fornecem referências quando a informação não está disponível no contexto nativo do FIFA:

- `club_manager_fallback.tsv`: identificação/modelo do técnico do clube.
- `coach_identity.tsv`: complemento da identidade/nacionalidade dos técnicos.
- `club_formation_fallback.tsv`: referências de formação.
- `club_stadium_fallback.tsv`: referências de estádio do clube.

Não são saves e não são bancos de idioma. Foram apenas movidos; seus conteúdos foram preservados.
