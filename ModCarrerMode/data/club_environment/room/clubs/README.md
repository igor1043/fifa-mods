Artes de vestiário por ID do clube
================================

Crie uma pasta com o ID do clube e coloque mural.png (3:1).
Opcionais: sign_medical.png, sign_coach.png, sign_water.png, sign_exit.png (4:1).
Exemplo: 1043/mural.png. Não precisa alterar código para novos clubes.
Sem PNG próprio, as cores, o escudo e o nome são montados automaticamente.
Ao substituir arquivos, saia e entre no vestiário para recarregar a decoração.
